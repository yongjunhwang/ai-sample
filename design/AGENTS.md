# Blender 작업 지침

- 시작 절차와 연결 검증은 상위 `AGENTS.md` 적용.
- 기본 파일은 `work.blend`. 작업 전 읽기 전용 조회로 실제 파일 경로 확인.
- 기본 애드온 주소는 `127.0.0.1:9876`. 현재 대화에서 확정한 주소 사용.
- 도구가 없으면 Codex 재시작 안내. 접속 실패 시 Blender 애드온 활성화와 서버 시작 상태 확인.
- 기존 오브젝트·재질·컬렉션·애니메이션·미저장 작업 보존. 연결 점검 중 수정·저장·재로드 금지.
- 원본·텍스처·백업은 이 폴더에 보존. 필요한 결과만 `../development/Assets/`로 내보내기. `.meta`와 GUID 유지.
- 내보낼 때 단위·축·크기·재질·애니메이션과 실제 Unity 임포트 결과 확인.
- 변경 파일, 내보낸 에셋, 검증 결과, 수동 조작을 한국어로 짧게 보고.
